# Atomic Design Architecture

## Что такое Atomic Design?

Atomic Design (Атомарный дизайн) — это методология организации компонентов, предложенная Брэдом Фростом. Она делит интерфейс на иерархию компонентов от самых простых до самых сложных.

## Структура уровней

### 🟢 Atoms (Атомы)

**Самые маленькие, базовые компоненты, которые нельзя разбить дальше.**

Примеры:

- `Button` — кнопка
- `Input` — поле ввода
- `Label` — метка
- `Icon` — иконка
- `Heading` — заголовок

**Характеристики:**

- Не зависят от других компонентов
- Переиспользуемые везде
- Один компонент = одна ответственность

**Расположение:** `src/components/atoms/`

---

### 🟡 Molecules (Молекулы)

**Комбинации атомов, которые вместе выполняют простую функцию.**

Примеры:

- `NavItem` — элемент навигации (NavLink + стили)
- `SearchForm` — форма поиска (Input + Button)
- `FormField` — поле формы (Label + Input + Error)

**Характеристики:**

- Состоят из нескольких атомов
- Выполняют одну простую задачу
- Переиспользуемые, но более специфичные

**Расположение:** `src/components/molecules/`

---

### 🔵 Organisms (Организмы)

**Сложные компоненты, состоящие из молекул и атомов.**

Примеры:

- `Navbar` — навигационная панель (NavItem × 5 + Logo)
- `Header` — шапка сайта
- `TransactionForm` — форма транзакции
- `TransactionList` — список транзакций

**Характеристики:**

- Сложная структура
- Могут содержать бизнес-логику
- Часто специфичны для определенных страниц

**Расположение:** `src/components/organisms/`

---

### 🟣 Templates (Шаблоны)

**Макеты страниц без конкретного контента.**

Примеры:

- `PageLayout` — общий макет страницы (Navbar + Main)
- `AuthLayout` — макет для страниц авторизации
- `DashboardLayout` — макет для дашборда

**Характеристики:**

- Определяют структуру страницы
- Не содержат реальных данных
- Показывают расположение компонентов

**Расположение:** `src/components/templates/`

---

### 🔴 Pages (Страницы)

**Конкретные страницы с реальным контентом.**

Примеры:

- `Home` — главная страница
- `Budgets` — страница бюджетов
- `Transactions` — страница транзакций

**Характеристики:**

- Используют шаблоны и организмы
- Содержат реальные данные
- Связаны с роутингом

**Расположение:** `src/pages/`

## Правила работы

### ✅ DO (Делай так)

1. **Начинай с атомов** — создавай базовые компоненты первыми
2. **Композиция** — собирай сложные компоненты из простых
3. **Переиспользование** — используй существующие компоненты
4. **Одна ответственность** — каждый компонент делает одну вещь
5. **Изоляция** — компоненты не зависят от контекста страницы

### ❌ DON'T (Не делай так)

1. **Не смешивай уровни** — атом не должен импортировать молекулу
2. **Не дублируй** — если компонент уже есть, используй его
3. **Не создавай монолиты** — разбивай большие компоненты
4. **Не привязывай к данным** — атомы и молекулы должны быть универсальными

## Примеры использования

### Импорт компонентов

```typescript
// Импорт атомов
import { Button, Input, Label } from "@/components/atoms";

// Импорт молекул
import { NavItem } from "@/components/molecules";

// Импорт организмов
import { Navbar } from "@/components/organisms";

// Импорт шаблонов
import { PageLayout } from "@/components/templates";
```

### Создание нового компонента

**Пример: создание формы транзакции**

1. **Атомы** (уже есть):

   - `Input` — для ввода суммы
   - `Label` — для меток
   - `Button` — для кнопки отправки

2. **Молекула** (создаем):

   ```typescript
   // molecules/FormField/FormField.tsx
   import { Label, Input } from "@/components/atoms";

   const FormField = ({ label, ...inputProps }) => (
     <div>
       <Label>{label}</Label>
       <Input {...inputProps} />
     </div>
   );
   ```

3. **Организм** (создаем):

   ```typescript
   // organisms/TransactionForm/TransactionForm.tsx
   import { FormField } from "@/components/molecules";
   import { Button } from "@/components/atoms";

   const TransactionForm = () => (
     <form>
       <FormField label="Сумма" type="number" />
       <FormField label="Описание" type="text" />
       <Button>Добавить</Button>
     </form>
   );
   ```

4. **Страница** (используем):

   ```typescript
   // pages/Home.tsx
   import { TransactionForm } from "@/components/organisms";

   const Home = () => (
     <div>
       <h1>Главная</h1>
       <TransactionForm />
     </div>
   );
   ```

## Преимущества

✅ **Масштабируемость** — легко добавлять новые компоненты  
✅ **Переиспользование** — компоненты используются многократно  
✅ **Тестируемость** — легко тестировать изолированные компоненты  
✅ **Поддерживаемость** — понятная структура проекта  
✅ **Консистентность** — единый стиль интерфейса
